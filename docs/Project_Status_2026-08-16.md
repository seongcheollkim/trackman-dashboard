# DODOS Golf Solution 프로젝트 진행 현황

작성일: 2026-08-16

## 프로젝트 비전

TrackMan 데이터를 자동 수집하고 AI가 스윙을 분석하며, 연습 기록과 성장
과정을 장기적으로 관리하는 개인 골프 코칭 플랫폼 구축.

# Phase 1. 자동 데이터 수집 (완료)

## 완료 기능

-   LaunchAgent 기반 자동 실행
-   TrackMan 신규 연습 자동 다운로드
-   Supabase Storage 업로드
-   중복 다운로드 방지
-   실행 로그 및 재시도
-   JSON → DODOS DB 자동 적재
-   AI Snapshot 자동 생성
-   Daily Snapshot 자동 생성

## 현재 자동 파이프라인

``` text
LaunchAgent
    ↓
trackman_backup_wrapper.sh
    ↓
scheduled_dodos_pipeline.py
    ↓
scheduled_trackman_backup.py
    ↓
TrackMan JSON
    ↓
Supabase Storage
    ↓
trackman_backfill.py --commit
    ↓
Practice Session
Shots
Club Summary
AI Snapshot
Daily Snapshot
```
